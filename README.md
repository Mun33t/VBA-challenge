# Excel VBA Stock Analysis Automation

## Overview
This project demonstrates how to use **Excel VBA** to automate stock market data analysis.  
The macro-enabled workbook was designed to loop through large datasets of stock prices, calculate key performance metrics, and return a clean summary for decision-making.

## Objectives
- Automate repetitive stock data analysis in Excel.  
- Calculate yearly change, percent change, and total stock volume for each ticker.  
- Apply conditional formatting to highlight positive vs. negative returns.  
- Handle large datasets across multiple worksheets with a single macro.  

## Tools & Skills
- **Excel VBA (Visual Basic for Applications)**  
- **Automation & Macros**  
- **Financial Data Analysis**  
- **Conditional Formatting & Reporting**  

## Methods
1. Wrote VBA scripts to loop through thousands of stock ticker rows.  
2. Calculated:  
   - Yearly change in stock price.  
   - Percent change from start to end of year.  
   - Total stock trading volume.  
3. Applied conditional formatting (green = gain, red = loss).  
4. Consolidated results into a summary table for quick insights.  

## Results
- Automated stock performance tracking across multiple years of data.  
- Reduced manual analysis time from hours to seconds.  
- Produced an easy-to-read summary highlighting best and worst performers.  

## Why It Matters
Financial analysts and reporting teams still rely heavily on **Excel for quick insights**.  
Automating reporting with VBA ensures consistency, saves time, and reduces errors.  
This project demonstrates practical Excel/VBA skills that are directly transferable to **banking, insurance, and consulting workflows**.
